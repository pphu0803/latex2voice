Ask a stock TTS to read \limsup_{n \to \infty} a_n and you get “backslash lim sup underscore…” — or silence. Paper audiobooks, screen-reader access to lecture notes, video voice-overs: they all break the same way. latex2voice is a fine-tuned text-normalization front end that rewrites LaTeX into the sentence a person would actually say, then hands it to any TTS voice.

Use it

# works today: pull the LoRA from Hugging Face (Apache-2.0)
from peft import PeftModel
from transformers import AutoModelForCausalLM
base = AutoModelForCausalLM.from_pretrained("Qwen/Qwen3-4B")
model = PeftModel.from_pretrained(base, "petehu0803/latex2voice")
# tn("\limsup_{n \to \infty} a_n") -> "the limit superior as n goes to infinity of a sub n"
# then hand the spoken text to ANY TTS engine
