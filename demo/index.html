Ask a stock TTS to read \limsup_{n \to \infty} a_n and you get “backslash lim sup underscore…” — or silence. Paper audiobooks, screen-reader access to lecture notes, video voice-overs: they all break the same way. latex2voice is a fine-tuned text-normalization front end that rewrites LaTeX into the sentence a person would actually say, then hands it to any TTS voice.

Use it

# pip install latextts  — TN front end, any TTS behind it
from latextts import tn
spoken = tn(r"\limsup_{n \to \infty} a_n")
# -> "the limit superior as n goes to infinity of a sub n"
tts.speak(spoken)  # Kokoro, Piper, Azure… your choice
GitHub — source & model Hugging Face — weights
Everything here runs locally: LaTeX → spoken text (Qwen3-4B + LoRA, this project) → audio (Kokoro 82M). No API calls, works on a CPU laptop. Runtime footprint ≈ 2 GB RAM, ~3–6 s per formula on CPU; training was a 40-minute LoRA run on a consumer iGPU. English only for now — Chinese is planned.
Verification: every clip was round-tripped through Whisper and judged semantically equivalent to its source formula by an LLM judge.
